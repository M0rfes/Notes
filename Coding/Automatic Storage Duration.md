# Automatic Storage Duration

Auto is the default modifier for [[Variable Linkage|visibility]] & [[Variable Lifetime|lifetime]] is bound to its [[Variable Scope|scope]]; its memory is acquired when it comes into scope and freed when it goes out of scope.
