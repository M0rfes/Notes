# Concurrency

Concurrency is not a new concept, but it has gained popularity over the years as the number of cores and [[Threads|threads]] per core on modern CPUs has increased. And it's the only way to improve performance with limited resources.

Concurrency is important and widely used in modern computing systems, operating systems (OSs), and large distributed clusters. It helps model the real world, maximises system efficiency from users’ and developers’ perspectives, and enables developers to solve large, complex problems.
