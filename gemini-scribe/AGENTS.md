# AGENTS.md

This file provides context about this Obsidian vault for AI agents.

## Vault Overview

This vault is a comprehensive technical knowledge base and workspace centered on Large Language Models (LLMs), AI systems engineering (specifically the Gemini ecosystem), and robust software architecture.

It functions as both a deep-dive research repository for topics like RAG and microservices and a production environment for professional content creation, such as LinkedIn post drafts. The vault balances theoretical study with practical implementation details across approximately 41 specialized notes.

## Organization

The vault is organized into functional domains with a clear emphasis on categorization and temporal tracking:

- **Technical Repositories**: Specialized research is housed in folders like `LLMs/` (the most dense folder), `Architecture/`, `Coding/`, and `tools/`.
- **Output & Workflow**: The `posts/` folder contains drafted content organized by date-specific subfolders (e.g., `posts/2026-04-11/linkedin`), while `Daily Notes/` tracks chronological activities.
- **System & Templates**: Root-level files like `GEMINI` track high-level AI interaction context, while the `Statements/` folder contains foundational declarations and the `Agents/` folder defines interaction protocols.

Most technical notes follow a strict `topic-DD-MM-YYYY` naming convention to maintain a temporal record of learning progress (e.g., `DDIA-14-03-2026`), though core concept files in the `LLMs/` directory often use direct topical names (e.g., `Re-ranking`, `vLLM`, `LightRAG`).
